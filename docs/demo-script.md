# 3–5 分钟演示视频提纲（录制脚本）

> 总时长目标：4 分 30 秒。每段标了"画面/动作"和"话术要点"。
> 录制工具：Windows 自带 Xbox Game Bar（Win+Alt+R）或 OBS；分辨率 1920×1080。
> 建议提词方式：把要点贴屏幕上，照念，不要背稿。

---

## E1 开场定调（约 25s）

- **画面**：仓库 GitHub 页（README 顶部）→ 或项目目录树截图。
- **话术**：
  "这是我在 3 天内完成的无人机 GPS 诱骗检测与安全分析项目。目标一句话：
  给定一段飞行日志，判断是否被 GPS 诱骗、什么时候开始的，并且能在线的、逐时刻地判断。
  代码可复现：clone 后用一条命令跑完训练评测；仓库在 GitHub 搜索 uav-gps-spoofing-detector。"

## E2 问题与数据（约 45s）

- **画面**：`docs/dataset-notes.md` 字段表 + 数据目录树；某攻击航班的时间线图
  （`outputs/figs/timeline_m1.png` 前几秒画面）。
- **话术**：
  "数据集是 PX4 仿真采集的公开数据，360 个航段、250Hz、四类传感器（GPS/IMU/气压计/磁罗盘）。
  关键点：这是**隐蔽诱骗**——攻击对 GPS 位置每次只加一点点偏移，专门躲 EKF，
  所以单看任意传感器都'正常'，必须多源交叉验证或学习组合动力学。"
- **动作**：用 2 秒剪开 timeline 图说"红线是检测、蓝线是真值"（E4 详讲）。

## E3 方法（约 60s）

- **画面**：`report/report.md` 第 3 节（方法表）+ `src/` 文件列表。
- **话术**：
  "方法分三层：特征（L1 原始统计 + L2 物理一致性 + L3 滑窗聚合），5 个模型——
  规则阈值 M0、随机森林 M1、GBDT M2、BiLSTM M3、无监督孤立森林 M4。
  测评按航班划分，绝无时间泄漏；固定随机种子；一键流程 scripts/run_all.py。"
- **画面**：展示 `feature_importance_m1.png`（特征重要性）说
  "最重要的特征是加速度模/角速度模/姿态角的多变量组合——诱骗让飞控的动力学改变了。"

## E4 实验结果（约 45s）

- **画面**：`report/report.md` 5.1 指标表，鼠标从 M0 扫到 M3。
- **话术**（先亮结论再讲故事）：
  "M1 随机森林 AUROC 0.988、F1 0.947、误报率 8%、检测延迟 0.2 秒，是最好的一组。
  但更想讲两个'失败'：（1）我的 L2 一致性特征**并没有**带来增益——因为这版攻击只偏移
  水平位置，GPS 和气压计高度始终一致，特征天然失效；这被我做成了消融实验验证；
  （2）无监督方法完全崩了：孤立森林把正常航班的起飞降落判为异常，和标签反相关（0.33）。
  这两个失败是我在报告 5.4 里重点写的推断链，也是对我们团队认知提升最大的部分。"

## E5 现场演示——CLI（约 60s）

- **画面**：终端，双栏：攻击航班 vs 正常航班（命令预先写好，逐行粘贴）。
- **命令**：
```bash
python -m src.cli predict --input data/raw/PX4_Simulation_Data/Merged/Curved/Attacked/log_21_04_2023_07_21_03.csv
python -m src.cli predict --input data/raw/PX4_Simulation_Data/Merged/Curved/Normal/log_21_04_2023_07_42_07.csv
```
- **话术**：
  "攻击航班：spoofing: true，置信度 0.97，报警区间 [2939.1s, 3163.1s]；
  正常航班：不报警。全程逐窗因果流式推理，~450 个窗 6.6 秒跑完——约 100 倍实时。"

## E6 现场演示——API 服务（约 60s）

- **画面**：另一个终端起服务 + curl；或直接用浏览器访问
  http://127.0.0.1:8000/docs （FastAPI 自动生成 Swagger，UI 好看，建议直接用！）。
- **命令**：
```bash
uvicorn src.server:app --port 8000
curl http://127.0.0.1:8000/healthz
curl -X POST http://127.0.0.1:8000/predict_file -F file=@<某个攻击航班CSV>
```
- **动作**：Swagger 页面点开 `/predict_file` → 上传 CSV → 点 Execute → 截图 JSON 输出
  （spoofing: true + alarm_intervals）。这是整个视频最有说服力的镜头。

## E7 收尾（约 20s）

- **画面**：README 底部（声明）+ 仓库链接。
- **话术**：
  "局限和下一步都写在报告 5.4/5.5：数据是仿真、攻击标签是开关而非精确偏移时刻、
  下一步做飞行阶段分割后再无监督检测。仓库链接和完整报告在视频描述里，谢谢。"
