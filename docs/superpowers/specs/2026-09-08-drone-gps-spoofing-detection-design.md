# 无人机 GPS 诱骗检测与安全分析 — 设计文档

> 日期：2026-09-08 ｜ 对应任务：2026 推免短期综合任务（3 天）

## 1. 问题定义

给定无人机飞行日志（GPS/IMU/姿态/气压/磁罗盘多源传感器时间序列），判断飞行中是否发生 GPS 诱骗攻击及其发生时区间，并给出置信度。面向真实场景，检测器必须**因果流式**（每窗仅用当前与历史信息），并能解释检测依据（一致性特征来源）。

## 2. 数据

- UAV-GPS-Spoofing-Dataset（INFOCOM 2024 论文配套），PX4+Gazebo 仿真采集，正常/隐蔽诱骗两类航班，4 类传感器。
- 标签策略：优先使用数据自带攻击区间标注；若无时间级标注，按航班正常/攻击分段标注（确认后定稿）。
- 划分：按航班划分 train/test，防止相邻窗口泄漏。

## 3. 特征设计（三层）

- L1 原始传感器：GPS 位置/速度/加速度、IMU 加速度/角速度、姿态、气压高度、磁罗盘 → 滑窗统计量。
- L2 物理一致性（核心改进）：GPS 速度 vs IMU 加速度积分残差；GPS 位置差分 vs IMU 积分轨迹偏差；GPS 高度 vs 气压高度；航向一致性（速度方向/姿态/罗盘）；滑窗突变度。
- L3 时序聚合：2s 滑窗（mean/std/min/max/slope/kurtosis）。

## 4. 方法

| 编号 | 方法 | 定位 |
|---|---|---|
| M0 | 一致性残差阈值 | 规则 baseline |
| M1 | 逻辑回归/RF on L1 | 学习 baseline |
| M2 | RF/GBDT on L1+L2+L3 | 改进主力 |
| M3 | BiLSTM on 原始时序窗 | 深度对比（GPU） |
| M4 | 孤立森林/OCSVM on L2+L3 | 无监督线 |

## 5. 评估

- 指标：AUROC、AUPRC、F1、漏检率、误报率、检测延迟（攻击开始→首次报警秒数）。
- 固定随机种子；记录硬件环境；按航班划分。
- 输出：metrics.csv、ROC/PR 图、特征重要性、检测叠加时间线图。

## 6. 在线检测模块

- CLI：`python -m src.cli predict --input flight.csv` → JSON（报警、置信度、异常区间）。
- FastAPI：`POST /predict` 因果流式逐窗推理；`GET /healthz`。
- 推理与训练共用同一特征管线。
